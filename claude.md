Axilink — Smartphone-Controlled Desktop System with Interactive Screen Mirroring
Tech Stack: Spring Boot, STOMP over WebSocket, Flutter, Python, Azure Cognitive Services
◦ Developed a low-latency remote desktop control system over WebSockets (STOMP), enabling gyroscope-based mouse
movement, touch clicks, scrolling, and text input from a smartphone with 50ms end-to-end latency.
◦ Engineered user-interactive screen mirroring with touch control, draggable on-screen keyboard, and adaptive
streaming (480p–1080p, 5–25 FPS, JPEG compression, frame skipping), reducing bandwidth usage by 45% while main
taining smooth visual feedback.
